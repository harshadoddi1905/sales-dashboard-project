# Sales & Revenue Performance Dashboard

## Project Overview
This project analyzes sales data and builds an interactive dashboard to visualize business performance and insights.

## Tools Used
- Python (Pandas)
- Power BI
- GitHub

## Features
- Data cleaning and preprocessing
- KPI calculations (Revenue, Orders, AOV)
- Interactive dashboard with filters
- Sales trend forecasting
- Business insights generation

## Dashboard Insights
- West region generates highest revenue
- Technology category dominates sales
- Sales peak during Q4 months
- Top products contribute major revenue share

## Project Structure
- `data/` → raw dataset
- `scripts/` → Python code
- `output/` → cleaned data
- `dashboard/` → Power BI dashboard
